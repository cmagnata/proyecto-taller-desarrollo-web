# Sistema de Turnos

## Integrantes
- Cristóbal Magnata Veragua
- Marcos Contreras Cortés

## Problemática
Una organización con gran flujo de personas requiere ordenar el proceso de toma de turnos, para así poder brindar una experiencia más ordenada al usuario. El sistema permite solicitar un turno según el tipo de atención, visualizar el estado de la fila en una pantalla pública, y gestionar el avance de los turnos desde un panel de operador.

## Tecnologías utilizadas
- Git
- GitFlow
- GitHub
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Funcionalidades
Solicitar un nuevo turno según tipo de atención y generar turno.
Diferenciar los turnos mediante letras.
Visualizar el turno actual y tipo de atención.
Mostrar la cantidad de personas en espera y personas atendidas.
Llamar al siguiente turno desde el panel del operador.
Navegar entre las diferentes vistas del sistema.

## Instrucciones
- Descargar el repositorio
- Abrir el archivo "index.html" en un navegador
- El sistema cuenta con 3 vistas: Solicitud de turnos, Pantalla pública de espera y panel del operador 
- Usar los botones de navegación para desplazarse entre las vistas
